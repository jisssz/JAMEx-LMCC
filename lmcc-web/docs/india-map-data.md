# India Compliance Map Data

- Boundary dataset: **States (2024), LGD** (36 state and union territory features), distributed by Bharatlas.
- Upstream source: India's Local Government Directory (LGD), snapshot 2024.
- Dataset landing page and download metadata: https://bharatlas.com/view/gb_adm1
- Data license indicated by the distributor: CC0-1.0 / CC-BY-4.0.
- The bundled `public/data/india-states-lgd-simplified.geojson` is a derived, simplified copy for country-level visualization. The original dataset is 27,090,105 bytes; the bundled derivative retains all 36 feature records and selected name/code properties.
- The map observation dataset is a reproducible synthetic fixture generated with seed `2601024`. It is created only in the browser, is never sent to inspection/report/analytics APIs, and does not represent real enforcement activity.
- State/UT boundaries are administrative reference geometry only. They do not establish the location of an inspected product.
